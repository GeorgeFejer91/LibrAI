# LibrAI

LibrAI is the LibreOffice Writer counterpart to [WordPlai](https://github.com/GeorgeFejer91/wordplai). The project goal is equivalent user-facing functionality across both editors, with host-native implementation protocols for each.

**Project page:** https://georgefejer91.github.io/LibrAI/

## Scope and status

This repository currently contains the public project page and the project control plane. No LibreOffice extension or product implementation is included yet. The shared feature baseline, parity rules, and verification expectations are documented in [`for-ai/CROSS-PLATFORM-COMPATIBILITY.md`](for-ai/CROSS-PLATFORM-COMPATIBILITY.md).

## Project context

Start with [`AGENTS.md`](AGENTS.md) and [`for-ai/README.md`](for-ai/README.md). The LibreOffice integration API, supported versions, packaging, and native editing protocol remain undecided until implementation research.
