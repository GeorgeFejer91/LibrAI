LibrAI

LibrAI is a LibreOffice Writer writing assistant planned as the counterpart to WordPlai.

Project goal

Provide equivalent user-facing writing-assistant functions across Writer and Microsoft Word. The products may use different native APIs, interfaces, storage, and implementation protocols while preserving the same user control and safeguards.

Current scope

This project is at the scope and planning stage. This page and the project control plane define the goal and shared feature-parity contract. No LibreOffice product implementation is included yet.
